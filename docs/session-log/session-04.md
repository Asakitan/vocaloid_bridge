## 关键修复

- 直接音高改用音符的 SetDirectPitch 和原生音高单位转换，提交后重新取得对象核对；交互式绘线入口不适用于本宿主。
- 新 AI 片段从明确选择的声库推导语言；首个音符使用显式音素，后续可走原生 G2PA。
- 导入 WAV 前初始化 Region；轨道颜色按 0..15 调色板索引；正常 no-op 不再视作原生错误。
- VAE 使用明确的 VST 主机连接后进入 Manual；变声读取实际 .vtb2 模型。
- 原生 WAV 最后一个奇数 DATA 块缺少填充字节时仅兼容完整载荷，实际截断仍报错。
- 素材属性在独立 property.json 中验证，.vsclip 音符资源保持不变。
- 原生混缩导出整工程/整轨；之前无效的 start_seconds/end_seconds/tail_seconds 现在明确拒绝。分轨按自己的长度对齐比较，不伪造等长原生文件。
- 前台变化按 HWND/PID 归因；一次外部任务栏/浏览器切换造成的中断单独保留，不充作功能失败。
