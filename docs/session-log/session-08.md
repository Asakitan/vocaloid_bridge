## 实现

- `TransportOperations.cs`：原生设备枚举与明确设备ID的StandAlone传输，准备/状态/开始/停止/异步定位/释放。已准备状态限制会话变更，关闭先释放；峰值单位明确为dB，定位请求与原生观测分开。
- `TrackFreezeOperations.cs`：正式freeze/state/unfreeze，只使用session-owned WAV；按预送时间物化缓存，放置覆盖所有片段，冻结回放不重复应用已烘焙的音量/声像。原生解冻会删除文件，因此拒绝未知缓存路径。保存/克隆只恢复经过身份检查的原始标准效果旁路字段，不持久化冻结状态。
- `ProjectArchivePreservation.cs`：安装版schema区分已知字段，未知固定对象字段以JSON Pointer附着到原生实体；观察通知和真实提交历史保护删除/重建及undo/redo。只补未知字段、保留额外成员，不覆盖原生当前值或复活已删除的已引用音频。
- `ScoreOperations`、RPC、生命周期接入上述状态保护与历史边界。原始IsFrozen写入口只读化，改用完整冻结工作流。
- 36个工具、119个操作；新增检查纳入`verify_all.py`，未重跑全量未变项目。
