# 会话 29：AI 编曲原生音素转换

日期：2026-11-10。起点提交：`e44db6c10e6de28575c30c16f34b0417e108560b`。源码版本 0.20.0；完整目标继续进行。

## 实现

`score_compose` 对缺省 AI 音素使用目标声库、对应语言和临时原生会话调用 G2PA；检查完整单音节、候选、周围音符及原生加载。空候选使用两个不同的编辑器默认音素种子比较结果。候选从持锁模板生成，同卷硬链接独占发布后再打开核对；已有目标不覆盖。显式音素仍走原有路径。详见 [转换契约](../compose-phonemes-29.md)。

## 必要验收

主人要求仅做必要测试，且本轮中要求之后不再使用子 agents。本次仅检查改动 Python 文件语法并运行 `tools/check_compose_phonemes_29.py`；没有更改或构建原生宿主。初次运行在写入回执前被沙箱拒绝；授权运行的 [回执](../../artifacts/feature-acceptance-2dfe4fb88811/summary.json) 为 1 个功能用例及清理通过：asa 的日语 `い`、英语 `cat`、中文 `ni`、显式音素、保存重开、已有输出和三个不接受输入。没有自有前台切换或遗留会话。
