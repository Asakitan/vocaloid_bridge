# 会话 30：替换音符共用原生音素转换

日期：2026-11-10。起点提交：`98325334da3f7f7b80c0dd66c31c14452f71bbf4`。源码版本 0.21.0；完整目标继续进行。

## 实现

`score_replace_notes` 与 `score_compose` 共用 `vocaloid_bridge/compose.py` 的目标 AI 声库、原生单音节转换和独占发布流程。替换入口保持 `path` / `summary` 返回结构，验证后关闭内部原生会话；显式音素或原样保留源音素时仍直接序列化文件。源音符快照、选择器、标准表现及非音符工程数据沿用现有规划，持锁源归档贯穿候选生成。转换种子写入前检查最终请求的音素 sidecar 身份，避免种子恰与旧字段相同而推迟保护检查。

## 必要验收

只检查改动 Python 文件语法，并运行一次 `tools/check_replace_phonemes_30.py`；没有子 agents、额外套件或原生宿主构建。回执 `artifacts/feature-acceptance-97a3e0c14883/summary.json` 为 1 个功能用例及清理通过：asa 的改词源音符、新音符及原样保留源音符、日英中音素、力度和标准表现字段、非音符工程数据、文件返回结构、保存重开、不接受输入及 sidecar 保护。没有自有前台切换或遗留会话。源文件字节保持不变。

## 边界和下一步

该用例不证明任意声库、带追踪扩展的转换、取消、崩溃或实际发音质量。原生扩展守卫保持，待转换的扩展工程仍受其约束。下一步处理 `note.add` 的首音符上下文和截断问题；歌词失败恢复、普通素材未知字段、设备/DAW 及审查边界继续见 [TODO](../../TODO.md)。
