## 修改

- `media_recovery_list` / `media_recovery_resolve`：公开持久日志、乐观版本校验和明确选择，保留冲突原文，持久决定支持进程中断后恢复。
- `lyrics_apply`：验证完整短语、有效音素、音符身份和未选择字段，截断走现有事务回滚。
- 普通轨道/音符编辑：提交前验证已有控制器和自动化完整映射。
- 删除：绑定精确原生对象和后代，验证剩余身份及父关系；与原生撤销共同记录。
- 复制/跨工程：验证音高、控制器与自动化完整数值并复制未知字段，自动化非零点跟随偏移。
- 归档素材属性：使用现有独占日志发布，原生子进程验证 `.vsclip` 字节不变；不修改归档 sidecar。
- 扩展工程中的音频导入、编辑及效果走现有乐谱事务和提交前完整曲线验证。
