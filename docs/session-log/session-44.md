## 目标

支持新安装的 VOCALOID7，并默认选择最新安装版本；保留 V6、私有桌面与原生引擎。用户要求先停止挂起的构建/渲染并修正原因，再继续验证。

## 问题与修复

- 初始迁移沿用 V6 的运行时/API 假设。V7 使用 .NET 10，部分设置移至轨道，VMM 和部分音频入口不存在。改用产品条件编译、显式轨道作用域和明确不支持错误。
- 早期构建命令用分号串联渲染，构建失败仍跑旧 DLL。setup 现在检查退出码；构建产物和标记按产品隔离，运行时核对实际身份，缺失或失配停止。
- 迁移工程的 VoiceTypeID 为空，渲染 started=true 但没有进展。保持旧 asa ID `BLKEA452HDSKXLD7`，补默认类型 `920B779D-9854-4925-B64E-AB4E52BEAA1E` 后成功。初始化移到打开/克隆/导入入口，渲染只做校验；删除未奏效的 VAE、dispatcher、partial-renderer 和渲染前歌词归一化猜测。
- 取消读响应时原来可能留下失步连接。BaseException 路径关闭自有进程并标记未知结果，不吞 KeyboardInterrupt，不重放。
- 文件级编曲只认片段 aiVoice；改为优先轨道 voice，修正纯 V7 文件自动音素、音符默认格式及声库选择。
